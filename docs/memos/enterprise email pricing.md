# Enterprise AI Agent Pricing Strategy: "Selling Headcount"

Stop selling "API usage" and start selling "Digital Headcount." Enterprises budget for headcount, not compute tokens. By framing Toro as a digital workforce, we align our pricing with human replacement costs, drastically increasing the perceived value and bypassing IT budget scrutiny.

## 1. The "Base Salary + Overtime" Model
Instead of charging per email or per token, customers "hire" specialized AI Agents to fill specific roles in their organization.

### The Base Salary (Agent Seats)
You hire a specific Agent Persona for **$99 / month**.
*   **Examples:** QBO Reconciliation Agent, Accounts Receivable Agent, First-Line Support Agent.
*   **What it includes:** 
    *   Continuous syncing with the underlying system (e.g., QuickBooks Online ledgers).
    *   The agent's "standard working capacity" (e.g., **500 successful task resolutions** per month).
    *   Access to maximum intelligence Frontier models (`gpt-5.5-pro`) to guarantee flawless performance.

### Overtime Pay (Overage Protection)
If an agent is extremely busy and exceeds its 500 monthly tasks, it starts working "Overtime."
*   **Overtime Rate:** $0.50 per additional successful resolution.
*   **Why this is necessary:** If a customer goes viral and their First-Line Support Agent has to handle 5,000 tickets in a month, the token costs for `gpt-5.5-pro` could reach $500. The overtime rate ensures that high-volume clients automatically scale up your revenue, protecting Toro from catastrophic token bills.

## 2. The Compute Margin Math
Because we enforce the use of maximum intelligence Frontier models, a complex email thread interaction costs Toro ~$0.10 in pure compute. 

Here is how the "Base Salary + Overtime" model guarantees profitability:
1.  **Standard Usage:** If an agent hits its 500 capacity limit, the compute cost to Toro is $50. The $99 Base Salary secures a **50% gross margin**.
2.  **Low Usage:** If the agent only handles 100 tasks, the compute cost is $10. The $99 Base Salary secures an **89% gross margin**.
3.  **Overtime Usage:** Every task beyond 500 is billed at $0.50. The underlying compute is $0.10, securing an **80% gross margin** on all scale.

The enterprise client is happy because $99/mo is unbelievably cheap for an employee, and they only pay Overtime when the agent is explicitly driving massive, tangible business value at scale.
