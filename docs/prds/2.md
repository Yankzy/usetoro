# **OPERATIONAL PRD 2: TORO-002 (Macro-Correlated Business Brief)**
**DATE:** April 10, 2026
**TARGET SYSTEM:** Toro OS (Go/NATS Core)
**OWNER:** Lead Backend Engineer / AI Integration Lead

#### **1. PRODUCT OBJECTIVE & ICP**
* **End-User:** High-Net-Worth Tech Founder / SMB CEO.
* **Operator:** The 1-to-5 person CPA firm.
* **Problem:** Founders are blind to how global macroeconomic shifts (supply chain crashes, inflation spikes) specifically threaten their localized Profit & Loss (P&L).
* **Solution:** An automated intelligence engine that identifies a business's highest operational costs via QuickBooks, pulls real-time global news sentiment for those specific industries via Alpha Vantage, and uses an LLM to write a predictive advisory brief for the CPA to deliver to the client.

#### **2. SYSTEM ARCHITECTURE & DATA PIPELINE**


This feature requires a synthesis of local ledger state and global NLP sentiment:
1.  **Micro Oracle (QuickBooks CDC via Go):**
    * Aggregates 90-day trailing expense data to identify the top 3 highest spending categories (e.g., Logistics, Cloud Compute, Raw Materials).
2.  **Translation Matrix (Postgres):**
    * Maps standard QuickBooks expense categories to Alpha Vantage API `topics` (e.g., QuickBooks "Fuel/Auto" -> Alpha Vantage "Energy").
3.  **Macro Oracle (Alpha Vantage API via Python Microservice):**
    * Queries the `NEWS_SENTIMENT` endpoint for the mapped topics to return bullish/bearish scores and summary articles.
4.  **Synthesis Engine (LLM via Go Backend):**
    * Ingests the local spend data + global sentiment data and generates a structured, 3-paragraph advisory brief.

#### **3. DETERMINISTIC LOGIC & EVENT FLOW**
The brief generation runs on a monthly cron schedule or can be triggered manually by the CPA:
* **Step 1 (Expense Identification):** Go backend queries Postgres for the client's highest expense categories over the last quarter. 
* **Step 2 (Request Sentiment):** Go publishes a JSON payload to NATS: `macro.sentiment.request` with the required topics (e.g., `["technology", "manufacturing"]`).
* **Step 3 (Fetch & Score):** Python microservice hits Alpha Vantage, filters for articles with a "relevance_score" > 0.8, and calculates the average "ticker_sentiment_score". 
* **Step 4 (Return Data):** Python publishes the aggregated sentiment and top 3 article summaries back to NATS: `macro.sentiment.response`.
* **Step 5 (LLM Generation):** Go backend receives the response, constructs a rigid system prompt, and calls the OpenAI/Anthropic API to draft the brief.
* **Step 6 (Storage):** Go stores the drafted brief in Postgres and fires a notification to the Wails UI.

#### **4. MICROSERVICE ENGINEERING TASKS (PYTHON & GO)**

**Task 4.1: Postgres Schema Updates (Go Core)**
* Create `Category_Mappings` table. Fields: `qb_category_name` (String), `alpha_vantage_topic` (String).
* Create `Advisory_Briefs` table. Fields: `brief_id` (UUID), `client_id` (UUID), `status` (Enum: Draft, Sent), `content` (Text), `macro_data_snapshot` (JSONB), `created_at` (Timestamp).

**Task 4.2: Alpha Vantage Sentiment Microservice (Python)**
* **Input:** Listens to NATS `macro.sentiment.request`.
* **Process:** Calls Alpha Vantage `function=NEWS_SENTIMENT&topics={requested_topic}`.
* **Logic:** Parse the JSON response. Isolate articles from the last 7 days. Extract `title`, `url`, `summary`, and `overall_sentiment_score`.
* **Output:** Publishes sanitized JSON back to `macro.sentiment.response`.

**Task 4.3: LLM Synthesis Worker (Go)**
* Build an integration with Claude 3.5 Sonnet or GPT-4o.
* **System Prompt Constraint:** *"You are an elite Fractional CFO. You will be provided with a client's highest expense category and the current global market sentiment for that sector. Write a concise, 3-paragraph executive summary detailing the macro risk and suggesting a specific operational defense (e.g., stockpiling inventory, locking in fixed-rate contracts). Tone must be highly analytical and unemotional."*
