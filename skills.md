Claude creates a skill by following the DBS Framework (Direction, Blueprints, Solutions) to automate a step-by-step process. Here is how the process works in Claude Co-work:

Defining Intent (0:12): You explain to Claude what you want to automate, and it uses a Skill Creator agent to understand your goal.
Structuring the Skill (1:49): Claude sets up a folder structure containing a skill.md file, which includes:
Metadata: A name and description to know when to trigger the skill (2:35).
Workflow: The step-by-step instructions for the task (3:18).
Rules: Constraints and guardrails for the output (4:25).
Adding References (Blueprints) (5:20): Claude creates a references folder to hold static context files, such as brand guides, voice guides, or past data, to shape the final output (6:02).
Adding Scripts (Solutions) (7:05): If the task requires advanced calculations, file formatting, or connecting to an external API not supported, Claude can generate a scripts folder containing code (like Python) to solve the problem (7:25).
Testing and Evaluation (20:00): Claude runs test cases in parallel to evaluate the skill's performance and allows you to iterate on the results before finalizing it (22:10).
